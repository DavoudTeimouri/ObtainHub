Data flow: CLI/WebUI → Core (download, registries, config, state) → External (GitHub, Crates.io, Windows OS). All downloads go through core::download::to_file() which writes to a .part file and atomically renames on success. Retries use exponential backoff with 429 rate-limit awareness.
